# 🛍️ ShopNest — Full-Stack E-Commerce Store

**A modern online shopping experience powered by React, Node.js, Express, and MongoDB.**

ShopNest is a full-stack e-commerce web application designed to simplify online shopping through an intuitive interface, user authentication, product browsing, cart management, and order processing.

## ✨ Key Features

- **Product Catalog** — Browse products and explore detailed product information.
- **User Authentication** — Register and log in to your account.
- **Shopping Cart** — Add products and manage your shopping selections.
- **Wishlist** — Save favorite products for later.
- **Order Management** — Place orders and view order history and status.
- **Database Integration** — Store and manage products, users, and orders using MongoDB.
- **REST API** — Connect frontend functionality with backend services.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| React.js | Interactive user interface |
| JavaScript, HTML5, CSS3 | Frontend development |
| Node.js | Server-side runtime |
| Express.js | Backend and REST APIs |
| MongoDB | Database |
| Mongoose | Database modeling |
| JWT | User authentication |
| bcryptjs | Password hashing |
| Vite | Frontend development and build tooling |

## 🏛️ Architecture

ShopNest follows a client-server architecture:

- **Frontend:** Handles the user interface and shopping interactions.
- **Backend:** Processes requests, authentication, and application logic.
- **Database:** Stores product, user, and order information.
